# FEM Wallet Legal Docs Site

This workspace contains a multi-page static website for FEM Wallet legal and privacy documentation.

## Pages

- Help home: index.html
- FAQs: faq.html
- About: about.html
- Support: support.html
- Security guidance: security.html
- Privacy Policy: privacy-policy.html
- Terms of Service: terms-of-service.html
- Shared styling: styles.css

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/
- http://localhost:8000/faq.html
- http://localhost:8000/about.html
- http://localhost:8000/support.html
- http://localhost:8000/security.html
- http://localhost:8000/privacy-policy.html
- http://localhost:8000/terms-of-service.html

## Notes

This is a static, FEM-branded legal-doc structure with multiple pages and a shared design inspired by help-center layouts, adapted for the FEM wallet app.
